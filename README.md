## Wheel (`/wheel/`)

Spinner wheel with custom options.

- `?options=Pizza,Tacos,Sushi` — comma-separated, or repeat the param (`?options=Pizza&options=Tacos`). Underscores become spaces. Defaults to Yes/No if fewer than 2; max 50.
- `?title=Lunch_time` — optional heading.
